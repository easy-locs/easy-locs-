# Easy-Locs — Plateforme de Gestion Locative

## Description

Easy-Locs est une plateforme SaaS de gestion locative multi-pays permettant aux propriétaires et bailleurs de gérer leurs biens, locataires, baux, quittances et obligations administratives.

## Fonctionnalités

- Gestion de biens immobiliers (23+ pays européens)
- Gestion des locataires et baux conformes par pays
- Génération de documents PDF (quittances, baux, avis)
- Messagerie interne bailleur/locataire
- Portail locataire dédié
- Paiement en ligne des loyers (Stripe Connect)
- Assistant personnel IA
- Support multilingue (FR, EN, ES, DE, IT, PT)

## Stack technique

- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Backend Cloud (PostgreSQL, Auth, Storage, Edge Functions)
- Stripe (paiements et abonnements)
- SendGrid (notifications email)

## Développement local

```sh
npm install
npm run dev
```
