ORBIT PASS12 — CONNECTIONS / END-TO-END ACTION / SCRIPT BRIDGES

What was improved in this pass:

1. Orbit connection gateway
- Added src/lib/shared/orbit-connection.ts
- New requestJson() helper with:
  - timeout
  - retry
  - auth header wiring
  - apikey wiring
  - sync event emission
- New invokeEdge() helper for GET/POST Supabase Edge Function calls
- New bridgeAsync() helper to wrap async Supabase RPC / insert flows and keep Orbit sync state cleaner

2. Wallet connection flows hardened
- useWallet now uses the shared connection gateway instead of mixed direct fetch logic
- purchaseLocs uses invokeEdge()
- getConversionPreview uses invokeEdge()
- transfer_locs and request_locs are bridged through bridgeAsync()
- This reduces scattered GET/POST logic and keeps payment connection flows more consistent

3. CommunicationCenter flash sync improved
- CommunicationCenter now reloads on:
  - bus message events
  - bus call events
  - bus thread creation events
  - bus booking / document / wallet events
  - browser online event
  - browser focus event
  - visibility change when tab/screen becomes visible again
- This improves end-to-end action feeling and reduces stale conversation states

4. OrbitAppShell realtime bridges expanded
- Added wallet realtime channel bridge:
  - wallet_transactions
  - wallet_balances
- Added property/documents realtime bridge:
  - documents
  - leases
- Added live tracking realtime bridge:
  - live_trackings
- Added stronger online/focus/visibility refresh behavior
- Now more small streams communicate instantly through the bus

5. Direct thread creation now emits Orbit event
- src/lib/direct-thread.ts now emits orbit:thread_created when a direct conversation thread is created
- Better end-to-end link between messaging initiation and Orbit refresh surfaces

6. Communication pipeline now emits bus events
- src/lib/shared/communication-pipeline.ts now emits:
  - orbit:message_sent
  - orbit:notification_created
- This gives faster Orbit-wide sync after communication actions

7. Call event logger now emits Orbit events
- src/lib/call-thread-logger.ts now emits orbit:call_ended after inserting the related system message
- Better connection between call logs, messages, and Orbit state

8. Platform bus refresh list extended
- orbit:thread_created added to the core refresh-trigger list

Validation
- npx tsc --noEmit => PASS
- Vite production build could not be fully verified in this environment because vite binary is not installed locally here

Main purpose of pass12
- connect more of the little streams together
- reduce broken end-to-end action feeling
- centralize GET/POST / edge / rpc connection behavior more cleanly
- improve flash sync between communication / wallet / tracking / documents / Orbit
