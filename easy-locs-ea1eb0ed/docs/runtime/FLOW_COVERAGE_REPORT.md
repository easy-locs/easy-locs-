## Flow Test Criteria

For each flow:
- [ ] Page opens without black screen
- [ ] Primary buttons are clickable (no dead elements)
- [ ] Navigation links work (no broken hrefs)
- [ ] Modals open/close correctly
- [ ] Forms do not crash on submit attempt
- [ ] Empty states are visible when no data
- [ ] No silent unexpected redirect
- [ ] No uncaught JS exception
- [ ] No error boundary triggered
