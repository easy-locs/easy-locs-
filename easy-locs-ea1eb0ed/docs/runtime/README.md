# Runtime Documentation

This directory contains runtime verification artifacts generated by the Easy-Locs CI/CD pipeline.

## Files

| File | Description | Generator |
|------|-------------|-----------|
| `ROUTE_INVENTORY.md` | All app routes with auth level | `scripts/generate-route-inventory.cjs` |
| `ROUTE_INVENTORY.json` | Machine-readable route data | `scripts/generate-route-inventory.cjs` |
| `CLOUDFLARE_STRICT_REPORT.md` | Cloudflare config verification | `scripts/check-cloudflare-strict.cjs` |
| `SUPABASE_RUNTIME_GUARD.md` | Supabase lazy access audit | `scripts/check-supabase-lazy-access.cjs` |
| `DIST_ASSET_REPORT.md` | Build output asset verification | `scripts/check-dist-assets.cjs` |
| `FINAL_DEPLOY_VERDICT.md` | Aggregated go/no-go verdict | `scripts/generate-final-verdict.cjs` |
| `REPAIR_BACKLOG.md` | Tracking for known failures | Manual / `generate-final-verdict.cjs` |
| `PLAYWRIGHT_ROUTE_MATRIX.md` | E2E smoke test results | `e2e/route-matrix.spec.ts` |

## Verdict Meanings

- `SAFE_TO_MERGE` — All blocker gates passed and hosted verification confirmed
- `KEEP_OPEN_RUNTIME_VERIFICATION_REQUIRED` — Gates passed but no BASE_URL for hosted check
- `DO_NOT_MERGE_BLOCKERS_FOUND` — One or more blocker gates failed

## Running Checks

```bash
# Cloudflare config
node scripts/check-cloudflare-strict.cjs

# Supabase lazy access
node scripts/check-supabase-lazy-access.cjs

# Route inventory
node scripts/generate-route-inventory.cjs

# Dist assets (after build)
node scripts/check-dist-assets.cjs

# Final verdict
node scripts/generate-final-verdict.cjs
```
